# v0.1.3: HTTP live updates and smaller controls

Live UI updates now use server-sent events (SSE) over same-origin HTTP instead of WebSockets. Terminal and desktop WebSockets are unchanged.

## Live updates

- A streaming POST receives snapshots, updates and heartbeats; separate POSTs send subscription commands. Both use the existing management-origin checks.
- Reconnecting restores authoritative snapshots and rejects stale deliveries. Hidden pages pause their stream and reconnect when visible again.
- Stream cancellation releases subscriptions. Bounded queues disconnect slow consumers, and command bodies have a 64 KiB limit.
- HTTP forms are no longer globally cancelled while live updates reconnect. This removes the submit guard that could prevent prompts when the live connection failed.

## Controls

Composer actions, floating controls and mobile navigation use 80% of their previous popular-button dimensions and icon sizes. Touch buttons shrink from 62.5px to 50px; desktop popular icon buttons shrink from 38.24px to about 30.59px. Composer spacing reserves the matching control size. Other popular buttons retain their previous sizes.

## CI fixes

The failed main runs for v0.1.1 and v0.1.2 both attempted a nested-submodule clone before their Git daemon was listening. The fixture now waits for Git's readiness message, with a bounded startup timeout, and awaits process shutdown.

The v0.1.1 run also exceeded the default five-second timeout in a disk-backed delegation/reopen integration test. That test now has a twenty-second timeout, consistent with other durable-storage integration checks. Test lint output is consumed once so repeated runs can reuse the result without reading locked streams. The composer acceptance helper uses the workspace's actual `agent` user.

## Verification

- Lint and TypeScript checks passed.
- Full local suite: 2,055 passed, 39 skipped, no failures.
- Git source and native delegation suites repeated four times: 100 passed, no failures.
- Composer layout acceptance passed on the running preview, covering mobile and desktop layout, scrolling, send, floating controls and terminal focus.
- Manual Chromium inspection confirmed 50px mobile navigation/composer controls and an active SSE connection.

Physical iPad Safari and iOS software-keyboard acceptance could not be checked here because no iOS simulator was available. The self-signed LAN certificate behaviour needs confirmation on the affected iPad.

Tagged publication requires full GitHub checks and native AMD64/ARM64 image verification before creating the release and advancing `latest`. `stable` is unchanged; publication does not restart existing installations.
