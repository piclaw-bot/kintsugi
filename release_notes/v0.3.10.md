# Kintsugi v0.3.10

## Review and structural code tools

Changes gains **Send to Agent…**, with a preview and explicit confirmation. Saving a review comment alone does not grant Agent access. The native and authenticated MCP `code_review` tool exposes only batches dispatched to that Agent; editing or deleting a comment revokes its dispatched revision. Uncertain delivery is never retried automatically.

`code_search` and `code_rewrite` use pinned ast-grep 0.51.0 parsers on AMD64 and ARM64. Rewrites default to previews; applying one requires a matching source revision and changes one regular UTF-8 workspace file atomically. Paths, parser resources, results and process output are bounded.

## File viewers

- CSV/TSV files open as filterable tables, with a Source toggle and the existing editor. Formulas and HTML remain inert text. Previews are limited to 2 MB, 500 data rows and 80 columns.
- Office Work panes preview DOCX, Excel spreadsheets, ODS and PPTX. They support sheet selection, slide navigation, zoom, reload and download. Legacy DOC/PPT, ODT and ODP are unsupported.

Office rendering uses pinned libraries, including the official SheetJS CE 0.20.3 distribution. Documents stay read-only in an opaque-origin sandbox with network access blocked. Macros are not executed and formulas are not recalculated. Server preflight bounds source size and actual ZIP expansion; browser rendering remains best effort, including image decoding and synchronous parsing.

## Idle conversation timestamps

An idle conversation ends with a temporary timestamp separator. It uses the last available message timestamp, formats it in the browser's local timezone, and disappears when work resumes. It is never stored as a transcript message.

## Pi 1.3

The coupled Pi packages are pinned to 1.3.0. Native Agents use the new document-cache eviction support, retaining unobserved documents for one minute. Scheduler ownership caches now follow live work. Code mode admits at most two native workers across workspaces, counting cancelled workers until they actually exit, with a 256 MiB VM limit per worker.

Kintsugi now uses Pi's corrected 500k Codex Sol context limit without a redundant app override; explicit user overrides still win. Title requests follow the updated thinking capabilities, including Haiku 5.5's supported off level.

The upgrade also includes upstream provider, model-switching, argument-validation and code-mode cancellation fixes. Pi 1.3 changes Kimi Code to Chat Completions; custom `kimi-coding` base URL overrides must include `/v1`. Existing overrides are not rewritten automatically.

## Verification

Local verification passed 2,509 tests with 39 skipped and zero failures across 340 files. Frozen install, lint/types and asset builds passed. Native-Harness checks cover document eviction, worker admission and cancellation; a copied 1.2 journal opened under 1.3 without modifying its source.

Manual desktop/mobile review confirmed idle → busy → idle transitions and reload stability. Los Angeles and Tokyo browser timezone overrides displayed different local times for the same stored UTC instant. Composer layout acceptance passed 89/89 checks in six explicitly partial, no-inference Chrome scenarios. Production-provider inference and physical mobile keyboards were not live-qualified.

## Operation and compatibility

System capability remains 3, app minimum 0, network-policy reader 2 and resource-policy reader 1. No new application environment variable or System operation is introduced. Explicit review consent, credential grants, network exclusions, custom release sources, version pins and paired rollback remain in place.

Publication advances `latest` after native AMD64/ARM64 verification. `stable` is unchanged. No existing installation is updated or restarted.

Before downgrading, stop active native tool calls and back up app data. Image rollback does not restore settings or journals.
