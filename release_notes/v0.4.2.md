# Kintsugi v0.4.2

The final transcript timestamp now has an explicit full-width, three-column layout: the timestamp stays centered between equal-width horizontal rules, including in narrow panes.

Browser-local formatting, the retained UTC instant and idle/busy behavior are unchanged. This patch contains no other application behavior changes.

Manual review confirmed alignment at 320, 393, 800 and 1,440-pixel viewport widths. Composer layout acceptance passed 89/89 checks across six explicitly partial, no-inference desktop/mobile Chrome scenarios.

No installation is updated or restarted by publication. The separate `stable` promotion remains an explicit operator action.
