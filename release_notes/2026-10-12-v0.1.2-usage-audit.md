# v0.1.2: subscription usage audit

Expired or unknown pacing no longer covers a partially used allowance with a full grey bar. The same rule applies to settings bars, rings and the Usage button.

## Provider data

- Copilot treats a zero reset epoch as missing timing. A future account reset can replace expired per-quota timing. When all reported dates have passed, consumption remains visible and pacing is unavailable; dates are not rolled forward. Known placeholders no longer suppress renamed premium buckets with real counts.
- Codex preserves valid additional, code-review and Chatpass windows independently of malformed siblings. Missing window timing leaves consumption visible. Camel-case workspace credit caps are recognised, and overflowing numeric balances produce a usage error.
- Claude skips unmetered buckets, preserves model display names and reported percentages above 100%, and isolates malformed additive scoped limits. Invalid header periods and out-of-range epochs produce usage errors. A successful probe without usage headers reports missing limits instead of an HTTP 200 error.
- xAI retains percentages without reset metadata, supports standalone prepaid wallets in USD cents, and ignores malformed optional wallets when allowance data is valid. Missing spend and missing usage remain unknown.
- Radius rejects malformed currency codes before money formatting.

Reset-date parsing consistently rejects ambiguous local timestamps and impossible calendar dates.

## Settings and pacing

- Pacing advances with the current clock even when Claude consumption comes from an older observed snapshot. JSON includes `timingAt` separately from the consumption snapshot's `checkedAt`.
- Visible usage frames refresh every minute and on tab focus. Hidden tabs and closed disclosures do not poll.
- Concurrent reads share only pending requests for the same provider, credential and refresh mode. Completed or failed requests leave no cached promise; changing credentials cannot reuse another account's pending response.
- Usage remains visible without pacing, including zero consumption and credit-only accounts. Unknown or long period labels respect the ring's three-character limit.
- Codex, Claude and xAI retain reported over-limit percentages in the metrics; their graphics are capped at 100%. Unrepresentable schedule distances remain unavailable.
- Zero-credit placeholders on unlimited chat/completion categories no longer add redundant credit captions.
