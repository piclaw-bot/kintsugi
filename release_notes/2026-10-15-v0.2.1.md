# v0.2.1

This patch incorporates upstream fixes through `d472c8d8` and includes the verified work committed since v0.2.0.

## Improvements and fixes

- Keep subscription re-authentication inside the provider’s card, with sign-in progress and browser-auth switching in the same place.
- Colour method calls as functions, leave property names plain, and give Cappuccino keywords a distinct terracotta colour.
- Preserve dictation’s final words by sending trailing silence before committing captured audio.
- Open the composer when creating a new built-in agent tab, including after lazy SSE loading. Mobile creation does not force keyboard focus; desktop creation focuses the prompt.
- Keep Claude Code busy until non-ambient background work has been reported, and stop those tasks when requested.
- Prevent iOS text autosizing and give mobile app settings more vertical space.
- Optimise long-session reload validation and tighten JSON request handling.
- Use configured fork attribution across image builders, source links and image cleanup. Reject reused manifests with absent or foreign source labels.
- Add local release preparation and pinned-revision support without changing channels during preparation. A main-branch fast-forward no longer invalidates a verified local build; rewritten history still prevents promotion.
- Hide upstream release-publication metadata in human notes and resolve explicit Git tags rather than potentially same-named branches.
- Isolate unit-test Docker discovery from running workspaces and handle ephemeral TCP/UDP fixture port collisions without retrying resolver assertions.

## Verification and limits

The local full suite passed 2,193 tests, with 39 skips and zero failures. Lint/types, frozen installs, System bundling and workflow validation passed. The provider-card flow was reviewed on desktop/mobile with a demo account and fake OAuth transport; no real account was re-authenticated by that review.

The six-scenario, no-inference Chrome layout subset passed 89 checks. Recorded speech passed through the real browser capture/controller and CPU ASR, retaining “These final words must survive” in the composer. This does not establish physical microphone or permission-prompt acceptance.

Full sending/busy/CLI composer acceptance still needs a connected model. iOS keyboard/rotation acceptance needs the remote simulator. Real private-GitHub notes access and a complete installation update/rollback cycle are not claimed by these fixtures.

System capability and app policy-reader format remain 2; the app minimum remains 0. Custom repositories, private registry access, pins, network protections and retained-pair downgrade safeguards remain intact.

Tagged GitHub Actions verifies native AMD64/ARM64 images and the candidate app/System pair before publishing app, System and workspace versions and advancing `latest`. `stable` stays unchanged. Publication does not restart installations.
